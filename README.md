# APS360 — ASL Alphabet Translator

**Author:** Kutlo Moseki  
**Course:** APS360, University of Toronto  

## Project Goal
A real-time ASL Alphabet Translator that classifies static 
hand signs (A–Z) from webcam imagery using a CNN.

## Dataset
[ASL Alphabet Dataset — Kaggle](https://www.kaggle.com/datasets/grassknoted/asl-alphabet)  
87,000 images across 29 classes (A–Z, space, delete, nothing)

## Stack
- Python / PyTorch
- Google Colab (training)

## Status
🟡 Proposal stage — architecture and training in progress
